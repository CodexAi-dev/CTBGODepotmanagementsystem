1. THE BIG PICTURE — WHAT IS THIS PROJECT?

Imagine a central Sri Lanka Transport Board (CTB / SLTB) bus depot in Kandy or Colombo. Dozens of buses operate daily on intercity and local routes. Historically, depot managers relied on heavy paper logbooks to manage fleet repairs, driver duties, fuel station bills, and hand-drawn schedules.

This project is a Windows Desktop Control Room Application built with Java 21, JavaFX 13, and Microsoft SQL Server (DepotDB) that digitizes and centralizes all depot operations into one software system.

🚍 Bus Fleet Management

Track all buses, seating capacities, vehicle health conditions, mileage, and scheduled servicing alert flags.

🗺️ Route & Schedule Control

Manage 9 route details including origin/destination terminals, distance in km, fare in LKR, and travel durations.

🪪 Employee & License Tracking

Store driver EPF numbers, assign rosters, and trigger Red Alerts ("EXPIRED") if heavy vehicle driving licenses expire.

⛽ Fuel Expense & GPS Map

Log every liter of diesel, monitor fuel costs, and view real-time bus coordinates on an interactive OpenStreetMap WebView.

6. COMMON VIVA & PRESENTATION QUESTIONS

Question Exact Answer to Give
What architecture is used? Model-View-Controller (MVC). Views handle UI, Controllers handle events, Services handle business rules, and DAOs execute SQL queries.
How is SQL Injection prevented? All DAO queries use PreparedStatement with parameterized placeholders (?), never concatenating raw user input into SQL.
How is password security handled? Passwords are hashed using SHA-256 before saving to SQL Server. An 8-failed-attempt lockout safeguard locks the account for 5 minutes.
How do you prevent UI freezing? Database operations run asynchronously on background Task threads, updating the JavaFX UI safely using Platform.runLater().
